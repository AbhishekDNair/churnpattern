# Customer Churn Intelligence Dashboard

An interactive intelligence console designed to analyze, predict, and mitigate customer churn patterns. Powered by HTML5, CSS3, and JavaScript.

## Core Features
- **Predictive Churn Simulator**: Run real-time risk calculations on sandbox profiles.
- **Dynamic Mitigation Playbooks**: Execute client saves that instantly update aggregate metrics and charts.
- **Glassmorphism Theme**: Neon violet, coral, and gold dashboard styling.
- **Data Table**: Search, filter, and page through active at-risk segments.
